# awesome-crypto-security

A curated list of crypto security resources - with a focus on materials for non-English speakers.

Maintained by [Srey Leak](https://github.com/sreyleak-security) - security researcher & anti-scam educator, Long Beach CA.

## Security Tools

- [Session Keys guide](https://github.com/sreyleak-security/polymarket-session-keys-guide) - scoped signer guide for Polymarket traders
- - [url-checker](https://github.com/sreyleak-security/multilingual-scam-detector) - lookalike-domain heuristics, no network calls
  - - Hardware wallets (Ledger, Trezor) - the only answer for long-term storage
